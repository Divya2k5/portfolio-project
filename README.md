# Portfolio Project — Setup Documentation

## Tools Installed

- **Cursor IDE** — Downloaded and set up from cursor.com.
  Already familiar with VS Code, so the transition was seamless since Cursor is built on top of it.
- **Claude Code Extension** — Installed via the Cursor Extensions Marketplace (Ctrl+Shift+X).
  Used the official Anthropic-verified extension (17M+ downloads, verified publisher badge).
- **Codex Extension** — Installed alongside Claude Code for AI-assisted development workflows.

## Steps Completed

1. Installed Cursor IDE and configured it to match my existing VS Code settings
2. Located the Extensions panel using Ctrl+Shift+X and installed Claude Code by Anthropic
3. Installed the Codex extension from the same Marketplace
4. Created a public GitHub repository named `portfolio-project`
5. Cloned the repo locally and opened it in Cursor
6. Wrote this README to document the process

## Issues Encountered & How I Solved Them

- **Cursor became unresponsive on first launch** — The window froze briefly right after opening
  for the first time. Closed and relaunched the application and it loaded without any issues.
  Likely a one-time initialization delay on fresh install.
